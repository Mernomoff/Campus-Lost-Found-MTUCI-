# ЛР №1: Проектирование UI/UX; формирование пользовательских сценариев; подготовка каркасного прототипа (wireframes)

## Цель лабораторной работы
Разработать пользовательский интерфейс и опыт взаимодействия для веб-приложения "Campus Lost/Found MTUCI" - системы поиска потерянных и найденных вещей в кампусе МТУСИ.

## Пользовательские сценарии (User Stories)

### Основные пользователи
1. **Студент, потерявший вещь** - хочет быстро найти свою потерянную вещь
2. **Студент, нашедший вещь** - хочет вернуть найденную вещь владельцу
3. **Администратор** - модерирует объявления и управляет системой

### Ключевые сценарии использования

#### Сценарий 1: Публикация объявления о потерянной вещи
**Как:** Студент, потерявший ноутбук
**Хочу:** Опубликовать объявление о пропаже
**Чтобы:** Найти свою вещь через других пользователей

**Шаги:**
1. Пользователь заходит на страницу "Добавить объявление"
2. Выбирает тип "Потеряно"
3. Заполняет категорию (Электроника)
4. Описывает вещь (Чёрный ноутбук Lenovo)
5. Указывает примерное местоположение
6. Публикует объявление

#### Сценарий 2: Поиск потерянной вещи
**Как:** Студент, нашедший ноутбук
**Хочу:** Найти владельца через поиск
**Чтобы:** Вернуть вещь законному владельцу

**Шаги:**
1. Пользователь заходит на страницу поиска
2. Вводит ключевые слова ("ноутбук", "чёрный")
3. Просматривает результаты поиска
4. Находит подходящее объявление
5. Переходит к деталям и начинает чат

#### Сценарий 3: Просмотр объявлений на карте
**Как:** Студент, ищущий вещь в определённом месте
**Хочу:** Посмотреть все объявления на интерактивной карте кампуса
**Чтобы:** Найти вещи, потерянные рядом с моим текущим местоположением

**Шаги:**
1. Пользователь переходит на страницу "Карта"
2. Видит карту кампуса МТУСИ с отмеченными местами находок
3. Кликает на маркеры для просмотра деталей
4. Фильтрует объявления по типу (потеряно/найдено)

#### Сценарий 4: Общение по поводу найденной вещи
**Как:** Пользователь, нашедший вещь
**Хочу:** Связаться с владельцем через чат
**Чтобы:** Организовать передачу вещи

**Шаги:**
1. Пользователь находит подходящее объявление
2. Переходит к деталям объявления
3. Нажимает "Начать чат"
4. Обменивается сообщениями с владельцем
5. Договаривается о встрече

## Структура приложения

### Основные экраны
1. **Главная страница** - список последних объявлений
2. **Страница поиска** - поиск по ключевым словам
3. **Страница добавления объявления** - форма создания нового объявления
4. **Страница деталей объявления** - подробная информация об объявлении
5. **Страница карты** - интерактивная карта с метками объявлений
6. **Страница чата** - общение между пользователями
7. **Страница профиля** - настройки пользователя

## UI/UX принципы

### Цветовая схема
- Основной цвет: Темно-синий (#1e293b)
- Акцентный цвет: Синий (#3b82f6)
- Фон: Градиент от темного к светлому
- Текст: Белый на темном фоне

### Типографика
- Заголовки: Жирный шрифт, размер 24-32px
- Основной текст: Обычный шрифт, размер 16px
- Кнопки: Жирный шрифт, размер 14-16px

### Навигация
- Фиксированная навигационная панель сверху
- Активный пункт меню выделен
- Простая и интуитивная структура

### Адаптивность
- Desktop: Полная ширина контента
- Mobile: Адаптивная верстка с колонками
- Touch-friendly элементы управления

### Доступность
- Высокий контраст текста
- Альтернативный текст для изображений
- Клавиатурная навигация
- Семантическая разметка

## Заключение
Прототипы и сценарии разработаны для обеспечения интуитивного пользовательского опыта в приложении поиска потерянных вещей. Дизайн ориентирован на простоту использования и эффективность взаимодействия между пользователями.
